# 灵境 · 新标签页（LJTab）

一款轻量、原生、注重性能的浏览器新标签页扩展。

支持多引擎搜索与联想、自定义搜索引擎、动态壁纸、主题配色、搜索历史与实时时钟，全部代码零第三方依赖。

## 功能特性

### 搜索

- 内置 Bing / Google / 百度 / 搜狗，搜索框左侧一键切换。
- 输入关键词时展示搜索引擎实时联想（需以扩展方式运行）。
- 自定义搜索引擎：
  - 填写名称与网站主页即可自动识别常见搜索模板；
  - 支持 `{q}` 或 `%s` 占位符，无占位符时自动追加关键词；
  - 自定义引擎持久保存，并支持单独删除。
- 搜索历史自动保留最近 50 条，支持匹配过滤、单条删除与一键清除。

### 外观

- 10 套诗意主题：晨曦、夜澜、樱花雨、翠微、紫梦、落霞、碧波、星河、森夜、暮金。
- 主题偏好自动记忆，颜色由 CSS 变量驱动，切换平滑。
- 自定义静态壁纸：支持 JPG / PNG / WebP，最大 20 MB，上传后自动压缩到合适尺寸再保存。
- 自定义动态壁纸：支持 MP4 / WebM 视频与 GIF，最大 100 MB，静音自动循环播放。
- 壁纸使用 IndexedDB 持久化，新开标签页依然保留；可随时一键移除恢复主题背景。
- 壁纸启用后自动采样画面亮暗，将起始页文字、强调色与面板整体切换为对应的浅色 / 深色中性配色，并叠加轻量遮罩保证可读性。

### 其他

- 实时时钟，按分钟边界更新，避免高频无意义唤醒。
- 按时段自动切换问候语。
- 自动识别 Chrome / Edge / Firefox / Safari。
- 桌面与移动端响应式布局。

## 环境要求

| --------------- | -------------------------- |
| Google Chrome   | ≥ 88（推荐）               |
| Microsoft Edge  | ≥ 88（推荐）               |

> 注意：搜索联想依赖扩展的 Service Worker 与网络权限，请务必安装为扩展使用；
> 直接双击打开 `newtab/index.html`（`file://`）时可以浏览界面，但联想功能会被浏览器 CORS 拦截。

## 安装与更新

### Chrome / Edge

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录 `LJTab`。
5. 新开一个标签页即可生效。

更新代码后：

- 若只修改了 `newtab/` 下的文件，可在扩展管理页点击“重新加载”；
- 若修改了 `manifest.json` 或 `background.js`，建议先移除扩展，再重新“加载已解压的扩展程序”，避免权限或 Service Worker 使用旧版本。

### Firefox

1. 打开 `about:debugging#/runtime/this-firefox`。
2. 点击“临时载入附加组件”。
3. 选择 `manifest.json`。

## 使用说明

### 切换引擎 / 添加搜索引擎

点击搜索框左侧当前引擎图标，在菜单中：

- 选择任意已保存的引擎；
- 点击“添加搜索引擎”；
- 名称示例：`Yandex`；
- 搜索地址可以只填主页，例如 `https://yandex.com/`，已识别网站会自动补全；
- 通用规则：用 `{q}` 标出关键词位置，例如 `https://example.com/search?q={q}`。

自定义引擎的 Logo 与联想地址会自动配置，无需手工填写。

### 切换主题 / 壁纸

点击右下角齿轮按钮：

- 上方区域选择主题；
- 下方“上传图片”设置静态壁纸；
- “上传动态”设置视频或 GIF 壁纸；
- 点击“移除自定义壁纸”恢复当前主题背景。

### 搜索历史

- 点击搜索框右侧历史按钮查看；
- 输入文字时历史会按匹配度排序；
- 单条可删除，右上角可“清除全部”。

## 性能设计

- 纯原生 HTML / CSS / JS，无第三方依赖与运行时框架。
- 历史与联想列表使用 `DocumentFragment` 批量写入，减少布局抖动。
- HTML 转义采用纯字符串实现，避免每次渲染创建临时 DOM。
- 关闭面板后立即释放面板内 DOM，避免隐藏节点长期占用内存。
- 联想结果带过期保护与 20 条内存缓存，避免旧请求覆盖新输入。
- 时钟只在分钟边界唤醒，页面切后台时暂停视频壁纸解码。
- 静态壁纸上传时自动等比缩放并转码，降低长期占用；
- 图片使用异步解码，避免大图阻塞主线程。
- 壁纸明暗识别结果会缓存，重开标签页无需重新分析即可立即应用适配字色。
- 当前搜索引擎自动建立 preconnect 连接，缩短搜索跳转时的握手耗时。

## 数据与权限

### localStorage

- 当前搜索引擎
- 自定义搜索引擎列表
- 搜索历史（最近 50 条）
- 最近使用的主题

### IndexedDB

- 自定义壁纸文件（`ljtab-wallpaper`）

### Origin Private File System（OPFS）

- 大体积动态壁纸会优先写入浏览器私有文件系统，适合存储数百 MB 甚至 GB 级视频；
- IndexedDB 写入失败时也会自动尝试 OPFS，避免大视频因配额/事务问题保存失败。

### Manifest 权限

- `unlimitedStorage`：允许保存较大壁纸文件
- 搜索建议域名 host 权限：Bing / Google / 百度 / 搜狗 / Yandex / DuckDuckGo

所有数据均保存在本地浏览器中，不上传、不收集任何用户信息。

## 常见问题

### 大视频壁纸保存失败

- 先到 `chrome://extensions/` **移除** LJTab，再重新“加载已解压的扩展程序”，确保 `unlimitedStorage` 权限真正生效；
- 上传新壁纸前可先移除旧壁纸，释放浏览器存储空间；
- 超过 48MB 的视频会自动改用 OPFS 文件系统保存，可靠性更高；
- 若仍失败，请查看面板提示的具体原因（存储配额或格式不支持）。
